# Compliance audit

This is a requirement-by-requirement check of [CHALLENGE.md](CHALLENGE.md). Each sentence of the spec is split into individual requirements.

**Status rules:**

- **Done:** there is a test, or code plus a document, that can be pointed to.
- **Partial:** only part of it is evidenced, or it cannot be fully satisfied from this repository.
- **Missing:** not done.
- **N/A:** outside the repository, or not applicable to this design.
- **Evidence outside the repository** (an email, for example) is cited as such and marked as stated by the author. Only 0.5 relies on it.

The rule is skeptical: without a test or code to point to, it is not Done.

**Evidence format:**

- _Tests_ are written as `file › test title`. All files are under `tests/`; e2e specs run on desktop and mobile Chromium unless noted.
- _Docs_ are files at the repository root or under `docs/`.

Audited on 2026-10-02 at the commit that adds this file. Full suite: see the end of this document.
