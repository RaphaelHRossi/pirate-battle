# Credits

## Game art, UI art and sounds

Everything under [`public/assets/`](public/assets/) was **provided with the challenge** (see [docs/CHALLENGE.md](docs/CHALLENGE.md) §7):

- ships and ship parts, projectiles, effects and tiles
- HUD and menu sprites, spritesheets, the scene background and the reference screenshots
- the WAV sounds

**Licence:** no licence file, readme or author attribution ships with these assets. The only text file, `tilesheet/tilesheets.txt`, gives the tile size. **The source and licence could therefore not be confirmed from the files.** They are credited here as provided with the challenge and used only for this submission. Their original licence terms, whatever they are, are not changed by this repository.

`logo_jungle_gaming.svg` is the Jungle Gaming logo; it is included with the assets and is not used by the game.

### Derived files

These are generated by the project, not drawn:

| File                                                                           | Made with                                                                                                                                        |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `public/assets/spritesheet/ships_miscellaneous_sheet.json` and `…_retina.json` | Converted from the provided Starling XML atlases by [`scripts/convert-starling-atlas.mjs`](scripts/convert-starling-atlas.mjs) (`npm run atlas`) |
| `tests/visual/__screenshots__/*.png`                                           | Screenshots of this game, generated by Playwright                                                                                                |

The 1× files are the only ones loaded: the "retina" ship art has the same pixel size as the default art (see ARCHITECTURE.md → Key decisions).

## Fonts

No font files are bundled. The UI uses the system font stack (`'Trebuchet MS', system-ui, sans-serif`).
